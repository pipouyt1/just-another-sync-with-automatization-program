# just another sync with automation program
jaswap for short is a program that can make variables and automations with low effort and 0 monetization **this is just a BETA, expect things to change**

## objective
this program is just a proof of concept of what multitasking from device to device could look like, as i stated before, this is a **proof of concept** and it's made with AI, i don't recommend that you store any personal data here, neither use your main password here, instead use a passkey or something alike

## installation
go to the releases tab and click the pc installer or the android apk depending on which device you are using, then install it, and select the cloud server or personal server, you can set up a personal server [here](set-up-localserver)

## security concerns
this app is **ai-generated**, it has a database on its own that the ai doesn't have access to, but it can still have some privacy concerns to some of you, that's why i want to make this clear now
