# just another sync with automatization program
jaswap for short is a program that can make variables and automatizations with low effort and 0 monetization **this is just a BETA, expect things to change**

## objective
this program is just a proof of concept of what multitasking from device to device could look like, as i stated before, this is a **proof of concept** and its made with AI, i dont recomend that you store any personal data here, neither use your main password here, instead use a passkey o something alike

## instalation
go to the realices tab and click the pc instaler or the android apk depending on wich device you are using, then instal it, and select the cloud server or personal server, you can set up a personal server [here](https://ejemplo.com)
